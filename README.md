# 切尔诺贝利 4 号机组：整堆控制棒的 AZ-5 示意

浏览器里的三维教学模型。它按第二代 RBMK-1000 的公开堆芯数字，画出整堆通道，并让控制棒从抽出位置一起响应 AZ-5。

带石墨挤水棒的棒一起向下：石墨先进入下部水柱，吸收体还在上面，定性曲线短暂为正；然后吸收体进入，曲线落到零以下。自动棒没有挤水棒。短棒从堆芯下面上来，不重复那段跳动。

页面是纯前端的。没有后端，没有账号，也没有数据库。

## 它展示什么

- 可旋转、缩放、平移的整堆。燃料通道 1661，石墨柱 2488，栅距 250 mm，堆芯直径约 11.8 m、高约 7 m。
- 一个「开始 AZ-5」。全部棒从抽出位置起算，按约 0.4 m/s 运动，时间轴约 18 s。
- 右侧切开，是为了看见石墨挤水棒进入下部约 1.25 m 的水。下部水柱在这段时间里变红，只是把这段标出来。
- 一条共用的定性曲线。正项是置换窗口上的 sin² 脉冲，负项是吸收体进入堆芯的比例。纵轴是任意单位。

## 它不展示什么

- 不是中子输运，不用截面库，不算功率，也不是安全分析。
- 不是 1986 年 4 月 26 日每一根棒的实测插深，也不是那天的功率过程。破坏性的功率增长发生在最初几秒，棒没有走完这段行程。
- 平面位置读自一张公开的堆顶通道图。燃料通道、石墨柱、USP、AR、LAR 与公开数字一致。图上控制棒色块是 221 个，公开资料通常写 211。多出来的格子按图面保留，并在页面上写明。
- 吸收体画出的长度、短棒约 3.5 m 的行程，是示意或公开量级，不是新的测量。
- 不画事故之后改过的控制棒，也不讨论武器或堆芯改型。

## 本地运行

需要 Node.js 22，或 Vite 8 当前支持的版本。

```bash
npm install
npm run dev
```

开发服务器监听 `0.0.0.0:4727`。打开 [http://127.0.0.1:4727](http://127.0.0.1:4727)。

`npm run check` 核对通道数量和挤水棒的几何顺序。

拖动旋转，右键平移，滚轮缩放。点「开始 AZ-5」。1× 是约 0.4 m/s；倍速只改变观看快慢。暂停停在当前棒位，继续从那里接着走。

## 资料

- International Nuclear Safety Advisory Group. *INSAG-7: The Chernobyl Accident: Updating of INSAG-1*. IAEA Safety Series No. 75-INSAG-7. Vienna: IAEA, 1992. 211 根控制保护棒，24 根从下方插入的短棒，12 根不带挤水棒的自动棒，约 1.25 m 的充水间隙，以及正紧急停堆效应。
- World Nuclear Association. “RBMK Reactors”. 约 4.5 m 石墨挤水棒，两端各约 1.25 m 水，紧急停堆全程约 18 s。
- 第二代 RBMK-1000 的公开堆芯数字：燃料通道 1661，控制棒通道 211，石墨柱 2488，栅距 250 mm，堆芯约 11.8 m × 7 m。短棒行程约 3.5 m 只取量级。
